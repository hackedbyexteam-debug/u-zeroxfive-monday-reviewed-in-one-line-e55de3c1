One funny one-line review of my Monday, under 200 characters. `main.ts` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).

> Monday gave me a 9 a.m. standup, 47 unread emails, and a coffee that went cold before I finished the first one — 2/10, would not relive.

136 characters. Deterministic, no input, no network.

## Run

```sh
node main.ts
```
